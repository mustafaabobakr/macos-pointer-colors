Apply it on your Mac

  1. Open System Settings › Accessibility › Display and scroll to Pointer.
  2. Click Pointer outline color, choose the sliders tab, set it to Hex Color, and paste the outline code.
  3. Do the same for Pointer fill color.
  4. Want it bigger? Drag Pointer size on the same screen. Reset brings back black and white.

Pointer Colors for Mac

A free menu-bar app that applies a pair in one click, so you never type hex codes.

  • Every pair on this page, plus your own
  • Pointer size slider, a separate color and size for each display, and a pair for each app
  • Switches pairs with light and dark appearance
  • Keyboard shortcuts, contrast warnings, English and Arabic
Download for macOS

macOS 14 or later. The app isn't notarized yet: the first time, right-click it and choose Open, or allow it in System Settings › Privacy & Security.
