# Pointer Colors promo: storyboard

1920×1080, 60 fps, about 38 seconds, no audio. One continuous camera move, no cuts.
Everything is drawn in `promo/index.html` and driven by one timeline, so any frame can be
rendered exactly (`promo/render.mjs`).

| Time | Shot | Camera | Caption |
| --- | --- | --- | --- |
| 0.0–3.5 | **Open.** Fade up on a MacBook Pro screen filling the frame. The default black pointer drifts across the desktop. | Flat on the screen, a slow push in. | "Your Mac pointer," |
| 3.5–6.0 | **Menu bar.** The pointer heads to the Pointer Colors icon and clicks; the menu springs open. | Push in to the top-right corner. | |
| 6.0–9.5 | **Pick a pair.** The pointer clicks Aqua mint; the real pointer turns mint at once. | Holds on the menu, slight drift. | "One click. Any color." |
| 9.5–12.5 | **Size.** The pointer drags the size slider; the pointer grows. | Holds. | "Any size." |
| 12.5–14.8 | **Displays.** Clicks "Separate colors for each display"; rows appear with a pair per display. The menu closes. | Holds. | |
| 14.8–19.5 | **Pull out.** The screen becomes a 3D MacBook Pro on a desk; keeps pulling back and up to reveal two external displays. | Long eased pull-back with a tilt and a turn. | "A color for every display." |
| 19.5–27.0 | **Cross displays.** The pointer moves up onto the left display (turns pink), across to the right one (turns blue), and back down to the MacBook (mint). | Slow orbit from left to right. | |
| 27.0–31.5 | **More.** The desktops switch to light appearance; feature chips float in: light and dark, a pair per app, shortcuts, 47 pairs, English and العربية. | Slow drift. | "And it keeps up with you." |
| 31.5–38.0 | **End card.** The scene dims and recedes; app icon, name, "Free for macOS", website. Fade to black. | Push back. | |
